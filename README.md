# PicACG_Next

[![GitHub](https://img.shields.io/github/license/Luxcis/PicACG_Next)](https://raw.githubusercontent.com/Luxcis/PicACG_Next/master/LICENSE.txt)
![HarmonyOS](https://img.shields.io/badge/HarmonyOS-ArkTS-green)

- 哔咔漫画鸿蒙客户端，界面使用ArkTS
- 该项目仅供技术研究使用，请勿用于其他用途
- 如果觉得本项目对你有所帮助，请点个star关注，感谢支持
- 如有使用中遇到问题，欢迎提ISSUE

## 功能
- [x] 首页排行榜、随机推荐、随机本子、本子妹推荐
- [x] 分类查询，关键字查询，搜索历史与搜索发现
- [x] 个人中心，签到，浏览历史，我的收藏，我的评论
- [x] 本子阅读：章节目录、上一章/下一章、阅读进度自动记忆与恢复
- [x] 阅读器设置：阅读亮度、屏幕常亮、点击翻页、隐私模式
- [x] 多账号管理，支持快速切换
- [x] 评论区浏览与回复，哔咔留言板，相关推荐
- [x] 暗黑模式
